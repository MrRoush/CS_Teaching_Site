Core capabilities

  • Teacher authoring: Reusable module templates support objectives, activity selection, quiz setup, and project prompts.
  • Assessment: Teachers can review submissions, apply point or rubric-style notes, and manage quiz feedback.
  • Gradebook: Course-level gradebook views combine project and quiz results by student and assignment.
  • Godot integration: Modules can launch the online Godot editor and link to starter project templates.
  • Scheduling: Assignment due dates can be attached to modules and surfaced across teacher/student views.

Classroom workflow highlights

  1. Create units/modules with lesson media, slide embeds, quiz configuration, and project expectations.
  2. Organize course pacing with assignment due dates and module sequencing.
  3. Have students submit playable project links and progress notes for each module.
  4. Review quiz attempts with comments, reassessment options, and updated scores.
  5. Use the course gradebook to monitor performance trends across all enrolled students.
