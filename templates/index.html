Feasibility snapshot

  • Authentication: Google Workspace sign-in is feasible through OAuth 2.0/OpenID Connect; this prototype keeps a demo session flow so deployment can start before district credentials are issued.
  • Teacher authoring: Reusable module templates let instructors assemble and trim course sequences without editing code.
  • Assessment: Each module supports lesson media, a quiz prompt, a project brief, submission tracking, and teacher grading notes.
  • Godot integration: The online Godot 4.7.2 editor can be linked immediately and conditionally embedded for supported browsers.
  • Privacy: Student data collection stays minimal in the scaffold and should move to managed auth, role checks, audit logs, and a production database before classroom rollout.

Clarifying questions to answer next

  1. What Google Workspace domain and admin approvals will be available for OAuth setup?
  2. Should modules support only links and text submissions, or should file uploads and rubric attachments be included in phase one?
  3. How should students enroll: teacher roster import, invite code, LMS sync, or manual assignment?
  4. Do quizzes need auto-grading now, or is teacher-reviewed short answer acceptable for the first release?
  5. Should the Godot editor save directly to cloud storage, GitHub, Google Drive, or a site-managed project store?
